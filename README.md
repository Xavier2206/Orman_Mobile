# ORMAN Mobile App

Proyecto Flutter para **ORMAN** siguiendo la arquitectura **Feature First + Clean Architecture pragmática**.

## 📁 Estructura del Proyecto

- `lib/app/`: Configuración global específica de ORMAN (router, temas, constantes).
- `lib/core/`: Infraestructura técnica transversal (red, errores, almacenamiento, utilidades).
- `lib/features/`: Módulos de negocio (se agregarán posteriormente).
- `lib/shared/`: Componentes reutilizables entre características.
- `lib/l10n/`: Internacionalización.
- `lib/generated/`: Código generado automáticamente.
- `assets/`: Recursos gráficos e imágenes fuera de `lib`.
- `docs/`: Documentación técnica y decisiones de diseño.
- `test/`: Pruebas unitarias y de widgets.
- `integration_test/`: Pruebas de integración.
- `scripts/`: Scripts auxiliares.
